# SKY · 💎 BLUE DIAMOND

یک سایت تک‌صفحه‌ای آبی، با الماس سه‌بعدی واقعی (WebGL) که با اسکرول توی صفحه سفر می‌کند.

**UI 2.0** — موبایل‌محور، بدون لگ، بدون کتابخانه‌ی سنگین.

---

## چی توش استفاده شده

| بخش | تکنولوژی | حجم |
|---|---|---|
| اسکرول نرم | [Lenis](https://github.com/darkroomengineering/lenis) 1.3 (vendored) | 16KB |
| الماس سه‌بعدی | WebGL خالص (شیدر دست‌نویس، بدون three.js) | ~4KB |
| فونت نمایشی | Estedad Variable (self-host) | 84KB |
| فونت متن | Vazirmatn Variable (self-host) | 80KB |
| بقیه | HTML + CSS + JS خالص | ~۹۰KB |

هیچ CDN خارجی‌ای استفاده نشده — همه چیز لوکال است (فونت گوگل هم لوکال شده تا در ایران راحت لود شود).

## کارهایی که با اسکرول اتفاق می‌افتد

- **الماس**: با اسکرول بین ۶ لنگر (`data-gem`) سفر می‌کند، بزرگ/کوچک و کم‌رنگ/پررنگ می‌شود.
- **متن‌ها**: خط‌به‌خط از پشت ماسک بالا می‌آیند (`[data-rise]`)، و کلمه‌به‌کلمه روشن می‌شوند (`[data-lit]`).
- **ترمینال**: وقتی به دید می‌رسد خودش تایپ می‌شود؛ دکمه‌ی «دوباره اجرا کن» هم دارد.
- **کارت‌ها**: استک چسبان — هر کارت روی قبلی می‌نشیند و قبلی کم‌رنگ می‌شود.
- **داک پایین**: حلقه‌ی پیشرفت + شماره‌ی بخش + نقطه‌ها + دکمه‌ی موسیقی (همه با شست در دسترس).

## تنظیم‌ها

**جای الماس** — در HTML هر لنگر این‌طوری است:

```html
<span class="gem-point" data-gem
      data-scale=".58" data-op=".28" data-glow=".38" data-spin=".55"
      style="top: 5%; inset-inline-end: -5%"></span>
```

- `gem-space` = لنگر درون‌جریان (hero) — ارتفاعش فضای الماس را تعیین می‌کند.
- `gem-point` = نقطه‌ی ۲ پیکسلی مطلق؛ فقط مرکزش مهم است.
- `data-scale` بزرگ‌نمایی، `data-op` شفافیت، `data-glow` هاله، `data-spin` سرعت چرخش.

**کیفیت خودکار** — اگر میانگین فریم از ۲۶ms بدتر شود، سایت خودش DPR را ۱ می‌کند،
نرخ رندر الماس را نصف می‌کند، انیمیشن‌های سنگین را خاموش می‌کند (`html.low-fx`)
و اسکرول لمسی را به حالت نیتیو برمی‌گرداند.

**دسترسی** — `prefers-reduced-motion` کامل پشتیبانی می‌شود (دک چسبان به لیست ساده تبدیل می‌شود)
و اگر جاوااسکریپت نباشد همه‌ی متن‌ها خوانا می‌مانند (`html:not(.js)`).

## دیباگ

در کنسول مرورگر:

```js
SKY.anchors      // لنگرهای الماس
SKY.sections     // آفست بخش‌ها
SKY.deck         // ابعاد دک
SKY.lenis()      // نمونه‌ی Lenis
SKY.to("#blue")  // اسکرول نرم به یک بخش
```
